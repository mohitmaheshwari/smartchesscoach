## How to run it

Set up each FEN. The side to move is yours. For each position, record the
answers **in order, each one before reading the next question**, because the
order is what separates recognition from evaluation:

1. **Is there a threat that needs a response? If so, what?**
2. **What do you play?**
3. **What do you expect after that?**

No clock. If you use a board, an engine or any hint, write that down against
the position — assisted and unassisted answers are different observations and
must not be pooled.

## What this does and does not establish

Some of these positions contain no threat. They are controls, and they are the
only way to tell *detecting* a threat from *agreeing* that one exists, so the
first question is deliberately a yes/no before it is a what.

Every outcome is a statement about performance **on this trial**, untimed.
Getting everything right here does **not** show that the clock is the cause of
anything — it shows the task is within reach under these conditions. His clock
survives on only 10% of his moves, so no timed claim is available either way.
