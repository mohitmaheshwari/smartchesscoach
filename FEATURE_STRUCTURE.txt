─────────────────────────────────────────────────────────────────────────────

1. COMPONENT MOUNT
   └─ CoachingPrescriptions.jsx mounts
      ├─ Parallel Fetch #1: GET /api/coaching/current-prescriptions
      └─ Parallel Fetch #2: GET /api/coaching/next-prescription

2. LOADING STATE
   └─ Show skeleton loaders (3 animated boxes)

3. SUCCESS STATE (Data Loaded)
   ├─ Map prescriptions → PrescriptionCard[] array
   ├─ Stagger entry animations (60ms per card)
   └─ Render NextRecommendation if data exists

4. ERROR STATE
   └─ Show alert box with retry option

5. EMPTY STATE
   └─ Show helpful guidance message

6. USER INTERACTIONS
   ├─ Click "Complete" on PrescriptionCard
   │  └─ POST /api/coaching/complete-prescription
   │     ├─ Backend: Update status → "completed"
   │     ├─ Backend: Record history entry
   │     └─ Frontend: Trigger page refresh
   │
   ├─ Click "Pause" on PrescriptionCard
   │  └─ POST /api/coaching/pause-prescription
   │     ├─ Backend: Update status → "paused"
   │     ├─ Backend: Record history entry
   │     └─ Frontend: Show success toast
   │
   ├─ Click "Accept This Plan" on NextRecommendation
   │  └─ POST /api/coaching/accept-prescription
   │     ├─ Backend: Update status → "active"
   │     ├─ Backend: Set first module as current
   │     ├─ Backend: Record history entry
   │     └─ Frontend: Trigger page refresh
   │
   ├─ Click Alternative Plan Card
   │  └─ POST /api/coaching/choose-alternative
   │     ├─ Backend: Create new prescription
   │     ├─ Backend: Set status → "pending"
   │     ├─ Backend: Record history entry
   │     └─ Frontend: Show success message
   │
   └─ Click "Add as Parallel" (if space available)
      └─ POST /api/coaching/add-parallel-plan
         ├─ Backend: Validate max plans not exceeded
         ├─ Backend: Create new prescription
         ├─ Backend: Set status → "pending"
         ├─ Backend: Record history entry
         └─ Frontend: Show success message

API ENDPOINTS
─────────────────────────────────────────────────────────────────────────────

✅ GET    /api/coaching/current-prescriptions
   Returns: Array of active/paused prescriptions
   Called by: CoachingPrescriptions (on mount)

✅ GET    /api/coaching/next-prescription
   Returns: Coach recommendation with alternatives
   Called by: CoachingPrescriptions (on mount)

✅ POST   /api/coaching/accept-prescription
   Accepts: {prescription_id, start_immediately}
   Called by: NextRecommendation (Accept button)

✅ POST   /api/coaching/choose-alternative
   Accepts: {plan_id, reason}
   Called by: NextRecommendation (Alternative card click)

✅ POST   /api/coaching/add-parallel-plan
   Accepts: {plan_id, reason, max_concurrent_plans}
   Called by: NextRecommendation (Add as Parallel button)

✅ GET    /api/coaching/prescription-history
   Returns: Audit trail of prescription changes
   Called by: (Admin/History page - not in this feature)

✅ POST   /api/coaching/complete-prescription (NEW)
   Accepts: {prescription_id}
   Called by: PrescriptionCard (Complete button)

✅ POST   /api/coaching/pause-prescription (NEW)
   Accepts: {prescription_id}
   Called by: PrescriptionCard (Pause button)
