**Key Technical Concepts**
-   **Asynchronous AI Coaching:** User moves return instantly while coach analysis (Stockfish + LLM) runs in a background task. The frontend polls for updates, creating a non-blocking UX.
-   **Personalized LLM Prompts:** Augmenting prompts with data from the user's game history () to generate tailored, non-generic advice.
-   **Structured Data for Rich UI:** The chat API returns structured JSON () instead of plain text, enabling the frontend to render complex UI elements like board arrows.
-   **Stateful Game Loop:** The backend maintains the full game state, including whose turn it is and whether the coach is thinking, which the frontend polls to drive the UI.
